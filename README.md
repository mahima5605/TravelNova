# ✈️ TravelNova – Travel & Tourism Website

TravelNova is a modern, fully responsive travel and tourism website designed to provide users with an engaging experience while exploring holiday destinations and travel packages. The website features a clean UI, attractive animations, and a user-friendly layout suitable for travel agencies and tour operators.

## 🌐 Live Demo

🔗 https://mahima5605.github.io/TravelNova/

---

## 📖 About the Project

TravelNova is a front-end travel website developed using HTML, CSS, JavaScript, and Bootstrap. It showcases beautiful travel destinations, holiday packages, booking pages, and contact information with a modern responsive design.

The project focuses on delivering an elegant user experience with smooth scrolling, animations, responsive layouts, and visually appealing sections.
